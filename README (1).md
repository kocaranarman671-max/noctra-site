# NOCTRA

Fictional market intelligence platform — an independent portfolio concept by **inv1zel**.

Live: https://kocaranarman671-max.github.io/noctra-site/

## What it shows
- Cinematic hero with a Three.js black-chrome sphere, orbital rings and mouse parallax
- Interactive market dashboard (custom SVG chart, animated range transitions)
- Paper-trading terminal: candlestick and line charts, live-forming candles, SMA, volume, horizontal levels, replay and a virtual account
- English / Russian interface, responsive layout, `prefers-reduced-motion` support

## Stack
Single-file HTML, vanilla JavaScript, Canvas 2D, SVG, Three.js (r128 via cdnjs).

## Disclaimer
All prices, indicators and articles are simulated sample content. Nothing here is financial advice and no real market data is used.
